```bash

git checkout release/v1.1.0-rc
git pull --ff-only origin release/v1.1.0-rc

npm.cmd run build
npx.cmd opennextjs-cloudflare build
```

After the controlled migration runbook is complete, deploy only with explicit approval:

```bash

```

## Rollback Commands

If deployment fails before traffic switches, stop and keep production on the current Worker.

If the new Worker is active and must be rolled back, use the Cloudflare-approved rollback path to restore version:

```bash
# Inspect versions first; do not guess IDs.
npx.cmd wrangler versions list

# Roll back to the certified production Worker version when approved.
npx.cmd wrangler rollback --name thetattoocore 0d73ea24-0c9c-4459-95f3-aacd15c9799d
```

If migrations have accepted production writes, prefer Worker rollback or a forward fix. Use database PITR only for severe migration/data corruption incidents.

## Post-Deployment Smoke Checklist

Set the base URL explicitly:

```powershell
$env:SMOKE_BASE_URL="https://thetattoocore.com"
```

Run:

```powershell
npm.cmd run smoke:public
npm.cmd run smoke:mobile
npm.cmd run smoke:mobile:narrow
npm.cmd run smoke:pwa
npm.cmd run smoke:profiles
npm.cmd run smoke:booking
npm.cmd run smoke:payments
npm.cmd run smoke:dm
npm.cmd run smoke:admin
npm.cmd run smoke:security
```

Manually verify:

- `/`
- `/search?q=ceocore`
- `/u/ceocore`
- `/u/ceocore/followers`
- `/u/ceocore/following`
- `/merch`
- `/messages` signed-out redirect
- `/notifications` signed-out redirect
- `/api/bookings/bad/calendar` signed-out gate
- `/admin` signed-out redirect plus `X-Robots-Tag: noindex, nofollow`
- `/api/admin/mail/test` signed-out denial
- `/manifest.webmanifest`
- `/sw.js`
- `/robots.txt`
- `/sitemap.xml`
- public 404 route

Check:

- Status codes and redirects.
- Private/no-store headers on private or auth-sensitive responses.
- Noindex on admin responses.
- No uncaught browser console errors.
- No failed application requests.
- No hydration warnings.
- No horizontal overflow at 320, 390, 768, 820, and 1440 widths.
- No unsafe HTML execution.
- No authenticated data in public caches.
