## Production Config Observed In Repo

`wrangler.jsonc` includes public Supabase URL/publishable key and native alert setup/registration enabled, with native delivery disabled. It also pins the optional seller checkout server release gate to `false` by default. It does not include Stripe secrets, seller URLs, seller account identifiers, Firebase private key, service-role, or mail password values.

## Secret Handling Rules

- Do not print or commit secret values.
- Do not copy production secrets into preview or docs.
- Keep native signing files and provider config files out of Git.
- The only current seller-link rollback control is `TTC_SELLER_CHECKOUT_LINKS_ENABLED=false`. Keep every retired TTC Checkout, Connect, marketplace, and destination-routing switch false; never use them as future seller-payout controls.
- Keep `TTC_SELLER_CHECKOUT_LINKS_ENABLED=false` until the protected migration, deployment approval, one privately reviewed seller-supplied live link, web/Android/TestFlight iPad QA, legal/privacy review, and rollback proof are complete.
- Keep `TTC_NATIVE_PUSH_DELIVERY_ENABLED=false` until Android and iOS delivery evidence is complete.
- Keep `TTC_CSP_ENFORCE_ENABLED` unset or `false` until production Report-Only evidence is reviewed.
